# Perceptron

Hardware design files for the Perceptron project.

## PCB Designs

This repository contains KiCad PCB designs for two boards:

- **PerceptronInput** - Input board with toggle switches and bi-color LEDs
- **PerceptronAdder** - Adder board with potentiometers for signal processing

## Tools

- PCB design: [KiCad](https://www.kicad.org/)

## Repository Structure

```
PCBs/
├── PerceptronInput/    # Input board design files
└── PerceptronAdder/    # Adder board design files
```

## Manufacturing

Gerber files can be generated from the KiCad project files for PCB fabrication.
