# Perceptron

This repository contains the PCB designs, manufacturing files (Gerbers), bill of materials (BOM), and build guide, everything you need, to build your own Perceptron, just like the one described in this video tutorial by Welch Labs: https://www.youtube.com/watch?v=l-9ALe3U-Fg.

## PCB Designs

The PCBs were designed using KiCad (https://www.kicad.org/), and you'll find the source files in the `PCBs` directory. There are two PCBs:

- **PerceptronInput** - Input board with toggle switches and bi-color LEDs
- **PerceptronAdder** - Adder board with potentiometers for signal processing
